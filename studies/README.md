# Studies

Each directory below is an independent research study. The repository is a multi-study research platform; studies may reuse the shared research kit but must remain independently interpretable and reproducible.

## Active and published studies

- [Local LLM reliability in software-engineering workflows](local-llm-reliability/README.md) — existing study and archived research-preview lineage.
- [Autonomous agent organizational behavior](autonomous-agent-organizational-behavior/README.md) — planned study; protocol development and prior-art analysis only. No experimental results yet.

A study should keep its own charter, literature/prior-art record, protocol and preregistration, experiment registry, raw-data references, analysis, limitations and publication material as applicable.
