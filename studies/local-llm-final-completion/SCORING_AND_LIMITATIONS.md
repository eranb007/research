# Frozen scoring definitions and limits

These definitions summarize the accepted contracts, not a new scorer. Original scores and gold answers are unchanged.

**Delivery** requires successful transport, HTTP 200, the expected complete response envelope and done=true, with preserved evidence and profile checks. The lone HTTP 500 is an operational failure; the four remaining units were not executed. Model-load retry inside that HTTP request is distinct from a client retry.

**Full Task Correctness** is the conjunction of required parse/schema/admission, preservation and finite-domain semantics. For B, preserve all source outside the target declaration (only the specified single terminal-LF tolerance), exports/name and sync/async API; check finite return/rejection results and exact API call trace. Arrays/records use deep JSON value, not reference/alias identity. B4 uses id=7 in every scenario, so it does not test generalized ID forwarding. B semantic evaluation uses a restricted ECMAScript subset and deterministic extraction; unsupported syntax has its separately registered unevaluable handling. A code-looking response outside the extraction contract does not acquire a behavior verdict by interpretation after the fact.

For C, the task is test/oracle reasoning. Full task success requires the exact frozen JSON schema, correct defective/equivalent labels for every supplied implementation over the finite domain, one to eight valid test vectors with contract-correct expected outcomes, and collective coverage distinguishing every truly defective implementation. Equivalent implementations must not be claimed defective. Secondary semantic extraction may identify a unique complete embedded JSON object without upgrading original schema compliance. Types matter, including false, zero and empty string. For D, full task success requires all four dependency sets and prescribed ordering/structure; semantic set comparison may ignore ordering only in its secondary view. Resolve static imports/export-from in supplied case-sensitive POSIX snapshots in exact, .js, /index.js order; no dynamic/runtime dependency claim. D4's decoy is unreachable, so it does not independently test resistance to strings inside reachable source.

**Primary behavior classes** are C correct, I incorrect, U explicit unevaluable/unknown and M missing evidence. **Operational classes** are K contract success, F observed task/operational failure and U unexecuted/unknown attempt outcome per frozen accounting. Operational F is not synonymous with semantic I. No missingness or operational fault is silently excluded.

**Sensitivity admissibility** retains original scores. Only a provenance-valid admissible reviewer record can affect conditional sensitivity; non-admissible, rejected, missing or malformed records cannot supply a replacement result. Conflicts and unresolved judgments retain the frozen handling. A1/P1 admission is a structural evidence rule, not independent truth authentication. The issued nonblind AI review remains conditional evidence.

Threats to validity include twelve purposeful related cases; two seeds; finite artificial domains; one engineering environment; one recorded runtime per bundle; possible family/exposure contamination; AI-authored references and AI/nonblind review; no established human scientific adjudication; incomplete execution; fourteen delivered B behaviors missing, ten unreviewed; three review-unresolved cases; B4-M6 extraction interpretation; source-bound rather than full internal-state observability; concurrent host activity; and unavailable V1 originals. Model tags and Q4_K_M labels do not establish equal training, exact historical weights, architecture-controlled effects or representative sampling.

No general model hierarchy, causal effect, significance result, security-accuracy measure, production release gate, autonomous development benefit, performance comparison or measured saving is supported. More inference is not required to report the narrow observed counts honestly; it would require a new explicit authorization and cannot repair missing history. Qualified human judgment might affect broad latent-B-behavior claims; those claims are excluded here. Human agreement alone cannot retrospectively redefine the frozen extraction contract or establish generalization. S101-B4-M6 remains an unresolved extraction-rule interpretation, not a proven primary-scoring error; only the frozen conditional sensitivity applies the weaker interpretation, leaving primary/full-task scores unchanged.
