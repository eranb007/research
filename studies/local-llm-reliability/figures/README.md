# Figure inventory

The sole figure is the selected-ledger coverage chart, in PNG and SVG. Source: [coverage CSV](../results/reconciliation-coverage.csv). Generator: [plot_coverage.py](../reproducibility/plot_coverage.py). Denominator: 585 selected differing fields in each version. Reviewed fields are derived as selected minus unreviewed; bounded assessment-unit counts are a different unit and are not drawn.

No model ranking, accuracy, error prevalence, statistical interval or completed historical adjudication is implied. Zero unreviewed fields permits explicit unresolved dispositions. Historical article diagrams and October model-performance charts are excluded pending exact current-claim/rights review. The [manifest](manifest.json) identifies source, status, export and limitations for the figure.
