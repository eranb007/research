# Research questions

1. Which bounded engineering tasks yield useful local-model outputs under explicitly recorded conditions?
2. How do delivery, structural admission, local correctness and whole-task completion differ?
3. When do evaluation procedures introduce false positives, false rejections or missed behavior?
4. Which source contracts and omitted platform assumptions determine whether a finding is supported?
5. What independent verification is required before output can enter a real development workflow?
6. How should later matched experiments measure verification effort, latency and execution economics?

Questions 1–4 have selected descriptive evidence. Question 5 motivates a prospective architecture; its end-to-end benefit is untested. Question 6 requires complete matched measurements that this preview does not supply. None defines a global model leaderboard.
